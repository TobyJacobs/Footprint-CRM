# Zoho Projects: what Footprint has today

_Gathered on 3 October 2026 from Zoho Projects (portal "footprintsouth", EU data centre). Settings, column names and value lists only. No project details are copied here._

## How it's used

- **One project per job.** Most project names include the sales order and quote numbers, for example "Customer – job – SO-010518 – QT-009666".
- Projects are numbered **FO-1 … FO-1497** (prefix "FO"). Most older ones are archived.
- There are also a few **ongoing internal projects**, such as production internal tasks and monthly retainer work.
- **Project groups** in use:
  - Swindon – Production
  - Swindon – Studio
  - Web Project
  - Marketing Retained
- **Statuses** seen: Active, Completed. Zoho also has its standard ones, such as On hold and Cancelled.
- Each project is **linked to the customer** (from Zoho CRM), and has an **owner** and a **% complete**.
- Projects record **expected revenue**, **expected GP** and an **invoice month**.
- **Billing method:** "Based on Staff Hours". Budget type: None. Planned and actual hours and cost columns exist but are mostly empty.
- **Tasks** are organised into **task lists** that act as **stages**. For example:
  - **Production:** materials due in → print → laminate → cut → mount → installed → job completed
  - **Finance & invoicing:** passed to finance → invoiced
  - The steps look template-driven, with the same checklist on each job of a type.
- **Modules switched on:** Projects, Tasks, **Milestones**, **Time logs** and Timesheets. Issues is switched off.
- **Layouts:** "Standard Layout" and "Social Media" (for social/marketing projects).

## Project fields (Standard layout)

Project name, Owner, Template, Start date, End date, Project overview, Status, Project group, Project income, Customer name, Invoice month (Jan–Dec), Expected revenue, Expected GP, Budget, Currency, Billing method, Budget type.

## What this means for the new platform

- A project belongs to a **customer**, and normally to a **sales order** (and so to its quote). The platform can create it straight from the sales order, so the SO/QT numbers don't need typing into the name.
- **Stages (task lists) with checklist tasks**, created from **templates** per kind of job (production/print, studio/design, web, marketing retainer).
- **Time logs** against tasks (date, person, hours, billable or not, notes), with **timesheets** per person and week.
- Project figures: **expected revenue / GP** come from the sales order. Actual hours come from time logs.
- **Not migrated:** the portal's personal settings. Archived projects can be imported read-only at go-live (Final wave).
